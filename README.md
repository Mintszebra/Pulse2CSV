# Pulse2CSV

本專案為 [tcm-pulse-local-client](https://github.com/Mintszebra/tcm-pulse-local-client) 的一部分，提供了一套完整的中醫脈象波形處理管線（Pipeline）。專案功能涵蓋了從原始影像提取波形座標、波形資料擴增、建立指紋數據庫進行脈象相似度比對，到擴增資料的視覺化輸出。

## 核心功能與模組

專案包含以下四個主要的處理模組：

### 1. 影像波形座標提取 (Image to CSV)
本模組負責將實體的脈波圖片數位化，轉換為可用於分析的座標點：
* 程式會掃描預設為 `maibo` 的資料夾，並讀取其中的圖片檔案（支援 .png, .jpg, .bmp 等格式）。
* 透過 OpenCV 讀取圖片並轉換至 HSV 顏色空間，藉由嚴格限制 V (亮度) 的上限，精準提取出黑色或深色的波形線條。
* 系統會計算出波形的 (x, y) 座標，並將結果輸出為 CSV 檔案，儲存於 `maibo_csv_results` 資料夾中。

### 2. 波形資料擴增 (Data Augmentation)
為了增加機器學習或比對系統的強健性，本模組會對原始脈象資料進行擴增：
* 系統會讀取 `pulse_data` 資料夾中，依據壓力級別分層（包含「沉」、「中」、「浮」三個子資料夾）的原始 CSV 檔案。
* 對每一筆波形資料進行三種擴充處理：對 y 值添加隨機雜訊的「抖動」(Jittering)、對 y 值進行整體倍率「縮放」(Scaling)，以及隨機截取資料片段的「切片」(Slicing)。
* 預設情況下，程式會為每個原始 CSV 檔案產生 50 個擴增檔案，並統一儲存至 `pulse_data_augmented` 資料夾中對應的壓力級別子資料夾。

### 3. 多數據庫相似度比對系統 (Jupyter Notebook)
此系統為第 7.0 版本，主要用於建立脈象基準庫並進行未知脈象的比對分類：
* 系統支援「沉、中、浮」三種壓力維度，並會從波形數據中提取關鍵特徵向量，包含平均值、標準差、最大最小值、差分數據，以及透過 SciPy 尋找的波峰數量。
* 程式會自動掃描 `pulse_data_augmented` 資料夾，對特徵進行標準化 (StandardScaler) 後，為每個壓力級別建立獨立且永久儲存的「指紋數據庫」。
* 進行預測時，使用者需輸入未知 CSV 檔案路徑與測量的壓力級別，系統會載入對應的數據庫，計算歐幾里得距離 (Euclidean distance) 後，回傳最相似的標準脈象樣本與其相似度。

### 4. 擴增資料視覺化 (CSV to PNG)
此模組用於將擴增後產生的龐大 CSV 數據，轉換回圖表以便於人工檢視：
* 程式會批次讀取 `pulse_data_augmented` 資料夾內由前一個模組生成的 CSV 檔案。
* 使用 Matplotlib 將 (x, y) 數據繪製成圖表，並自動輸出 PNG 圖片至 `csv2png_augmented` 資料夾對應的壓力級別子資料夾內。
* 程式內建字型檢測機制，會依序嘗試載入 Microsoft JhengHei、PingFang TC 或 Noto Sans CJK TC 等字型，確保圖表中的中文字元不會顯示為亂碼。

## 資料夾結構說明

若要順利執行本專案的所有腳本，請確保資料夾流向與結構如下：

1. `maibo/`：存放原始脈波圖片的輸入資料夾。
2. `maibo_csv_results/`：儲存由圖片萃取出的波形座標 CSV。
3. `pulse_data/`：存放手動整理好，分為 `沉/`、`中/`、`浮/` 三種壓力級別的原始基準 CSV。
4. `pulse_data_augmented/`：儲存經過抖動、縮放、切片擴增後的龐大 CSV 資料庫。
5. `csv2png_augmented/`：儲存由擴增 CSV 檔案繪製還原的 PNG 檢視圖片。
